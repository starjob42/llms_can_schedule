# LLMs Can Schedule

Clean source code for the Phi-3 job-shop-scheduling experiments.

The source dataset and related dataset tooling are maintained in the companion
repository: https://github.com/starjob42/datasetjsp

This branch intentionally excludes trained model weights, run outputs, caches,
large generated datasets, and publication artifacts. See
`experiments/phi3_revision/README.md` for the experiment layout and validation
commands.
